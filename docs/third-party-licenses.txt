libvips is dynamically linked, not vendored into the Go executable. The runtime
image retains Debian copyright/license records and shared libraries. The build
also copies downloaded Go modules' top-level LICENSE/COPYING/NOTICE/PATENTS files to
`/usr/share/doc/bytedown/modules`, including transitive and test dependencies,
and Go's license to `/usr/share/doc/bytedown/GO-LICENSE`. Inspect
the **actual built image**, because dependency/security revisions can change:

```bash
docker run --rm --entrypoint sh bytedown:local -c \
  'dpkg-query -W; cat /usr/share/doc/libvips42t64/copyright'
go list -m all
```

JPEG, PNG, WebP, HEIF/AVIF and their transitive libraries have distinct licenses;
Debian's native dependency tree can also include support for formats ByteDown
does not accept. Codec availability is probed, not a claim that every optional
format is enabled. Review the installed package inventory and exact copyright
files before redistribution. Retain required notices and provide corresponding
source/relinking rights as applicable under LGPL and other licenses; upstream
links alone are not a substitute for your distribution obligations. Debian
source packages are available from [Debian Sources](https://sources.debian.org/).
